# 期末复习网站

本项目帮助学生按课程管理课件，将文字形式的复习重点定位到具体 PPT 页面，并在阅读时完成 AI 答疑、笔记整理和习题练习。

当前处于需求与开发规划阶段，尚未初始化前后端工程，也没有可运行的业务功能。2026 年 10 月 27 日建立第一份规划文档基线；文档中的任务、用例和版本路线不代表已开发或已验收。

## 已确定的方向

- 前端采用 Vue 3，后端采用 Java 和 Spring Boot，AI 服务使用 DeepSeek API。
- 所有代码和开发文档均在本仓库管理，重要成果提交并同步到 GitHub。
- 先交付本地可运行版本，再按验收需要考虑在线部署。
- 提供基础注册登录；课程、课件、重点、笔记、练习和对话按用户隔离。
- 习题包含重点生成、学生上传、课件自动生成三种来源。
- AI 生成习题通过程序校验后即可练习，无人工发布审批步骤。
- API Key 由后端统一配置，限制调用规模；具体预算和额度待定。
