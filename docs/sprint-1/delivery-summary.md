## 技术交付

前端为 Vue 3、TypeScript，后端为 Java 17、Spring Boot，使用 MySQL、Flyway V1—V4、Apache POI、LibreOffice、PDFBox 与 Lucene。通过持久任务、来源修订和发布前校验管理提取、预览、索引、定位及删除。AI 定位可选，关键词主流程可独立工作；无 Docker，无 Python 业务服务。

`backend/` 保存后端、迁移和测试，`frontend/` 保存页面与交互，`scripts/` 保存本地启动与验证，`docs/` 保存需求和证据。课件、数据库、密钥、依赖和构建产物不随代码归档。当前启动说明见[README](../../README.md)，数据和来源映射规则见[课件流程](../material-pipeline.md)。
