## 样本与实际 AI 验证

上传与映射使用自行制作的 5 页 mapping-fixture，含普通、隐藏、空白、重复文字和图片页；另有本地8页与145页教师课件，相关文件只在本机。逐页锚点不能证明全部视觉版式相同。正式报告可用合成样本说明流程，教师正文及截图不进入公开 Git。

首轮定位真实调用为一条合成重点 `PAGE-01-NORMAL`：DeepSeek 返回第1页，连续原文校验通过，输入229/输出51 tokens，共280。该单次结果不是定位准确率测量；功能测试中的本地 HTTP 替身也不等于真实外部服务故障实验。后续侧栏文字/图片调用不计入首轮定位验证。
