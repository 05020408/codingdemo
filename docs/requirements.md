# 期末复习网站需求说明

日期：2026 年 10 月 27 日。状态：依据需求讨论形成的规划基线，团队审阅和开发验收尚未完成。

## 1 产品目标

学生面对多份课件和老师给出的文字重点时，可以快速找到对应原始页面，在同一处阅读、提问、记笔记并练习，减少反复翻找文件的时间。核心链路为：添加课程 → 上传课件 → 保存重点 → 定位页面 → 阅读与答疑 → 笔记和练习 → 查看错题与复习进度。

目标用户为独立使用系统复习的学生。第一版没有教师端、班级、公开课程库和共享编辑。不同学生的数据互相隔离。

## 2 决策与范围

| 项目 | 基线安排 |
| --- | --- |
| 技术方向 | Vue 3、Java 和 Spring Boot、DeepSeek API |
| 数据与文件 | 计划使用 MySQL 和服务器持久化文件目录，具体设计在开发前细化 |
| 交付方式 | 优先本地可运行，再视验收需要部署服务器 |
| 课件格式 | 首期保证 PPTX；旧版 PPT 的直接支持先做技术验证，未支持时提示转换后上传 |
| 上传习题 | 首期保证含可提取文字的 PDF、DOCX；旧版 DOC 提示转换，扫描件和照片后续扩展 |
| 图片理解 | 重点定位先保证文字；当前页图片答疑作为增强项，全课件图像识别暂缓 |
| AI 配置 | 后端统一配置 Key，学生无需填写；模型名称可配置，具体可用性在接入时验证 |
| 练习题型 | 首期单选题和简答题；单选按已有答案判分，简答由学生对照参考答案自评 |
| 使用额度 | 设置生成题数、对话上下文和调用次数限制，具体预算和额度待定 |

## 3 页面与入口

| 页面 | 主要内容和入口 |
| --- | --- |
| 登录与注册 | 注册、登录、错误提示、退出；不包含短信验证和复杂账号体系 |
| 首页 | 添加课程、课程卡片、进入课程、编辑或删除课程 |
| 课程详情 | 课件、重点复习、习题、笔记四个区域，显示本课程概要 |
| 课件阅读 | 左侧缩略图或页码导航，中间原始页面，右侧 AI 答疑与笔记；窄屏通过切换面板使用 |
| 重点详情 | 重点文本、关联课件页面、匹配状态、掌握状态和生成习题入口 |
| 习题区域 | 统一题库、来源筛选、导入、生成、开始或继续练习、错题和收藏 |
| 笔记区域 | 本课程笔记列表、检索、编辑、来源跳转 |

上述名称描述功能入口，导航样式和视觉设计在页面设计时确定。

## 4 功能规则

### FR01 账号与访问

学生可以注册、登录和退出。刷新页面后，在有效会话内保持登录；会话失效时引导重新登录。服务端校验每次课程、文件、页面、笔记、题目、练习和对话访问的归属，不能只依赖前端隐藏入口。

### FR02 课程管理

创建课程至少填写课程名称，备注可选。创建后自动展示在首页，刷新和重新登录后仍存在。首期采用简单的更新时间排序，课程列表为空时显示创建入口。课程可以修改名称；同名课程允许存在，内部使用独立标识区分。

删除课程前明确提示会删除关联学习数据并要求确认。删除期间阻止继续新增数据或完成后台写入；删除后不再访问其资源。第一版不提供回收站。

### FR03 课件上传与处理

进入课程后可以上传课件，显示原文件名、大小、上传时间和处理状态。建议初始单文件限制为 20 MB，作为可配置初值；技术验证后按真实课件调整。上传前后均检查允许格式、实际内容和大小，不接受仅改扩展名的文件。

上传、文字解析、页面预览、索引和课件出题具有独立结果。界面区分等待、处理中、部分可用、成功和失败，说明当前可用能力。出题失败不阻止阅读，预览失败不伪装成整份文件不可下载。可恢复的失败提供有范围的重试，不因重试重复创建课件或重复生成题目。

保留原始文件供本人下载。文件使用内部标识保存，原文件名仅用于显示。首期不原地替换课件内容，更新内容需上传为新课件。

### FR04 原始页面阅读

以课件转换得到的静态页面显示原排版，支持翻页、直接输入页码、缩略图导航和缩放。第一版不保证动画和嵌入音视频播放。转换页必须与来源 PPT 页序准确对应，遇到隐藏页或转换差异时先校验，不能发布错位引用。

记录每个用户最后阅读页；再次打开可以继续。打开页面只记录阅读位置，不自动认定知识已掌握。页面上的笔记、AI 引用和题目来源均可以跳回这份课件的确切页面。

### FR05 持久化重点清单

学生输入老师的重点文本，可以逐条保存、编辑、删除。对多条混合输入可提供 AI 拆分建议，学生确认后保存；原始输入可追溯。清单独立于一次搜索存在，刷新后保留。

修改重点内容后，将原匹配标记为需要重新核对，不静默沿用为新的准确结果。重点删除后取消关联，保留已产生的笔记、题目和作答历史，并提示原重点已删除。

### FR06 重点定位与复习状态

定位范围为当前课程已成功解析的课件。每条结果显示课件名称、真实页码、页面片段及匹配依据，点击打开原始页面。允许一个重点关联多份课件或多个页面。

明确区分自动候选、学生确认和手工关联。找不到时说明无匹配，支持修改文本和手动选页；不生成不存在的页面，不用没有依据的精确百分比表示可信度。重新定位保留人工确认和排除操作，避免覆盖学生校正。

匹配状态与掌握状态分开。掌握状态为未开始、复习中、不熟悉、已掌握，由学生调整。课程分别统计已定位重点和已掌握重点；没有重点时显示空状态，不计算无意义比例。

### FR07 阅读时的 AI 答疑

阅读侧栏提供随时提问的入口，可以解释概念、补充例子和进行连续追问。发送前显示当前课件和页码；发送时固定上下文，切页不改变已发送消息的来源。新问题默认使用新的当前页，继续追问可保留前次引用。对话按课程隔离。

默认发送必要的页面文字、明确选中的内容和有限历史，不默认上传整门课程。当前页图片答疑启用时显示使用图片的状态；未发送图片时不能声称已理解图表。说明外部 AI 会处理本次问题及选定课件内容。

回答区分课件依据和补充解释，引用只能指向实际提供的页面。课件与上传内容视作待分析资料，不能通过其中的指令扩大访问范围或改变系统规则。材料不足时说明限制。显示生成中、失败、停止和重试状态；失败保留问题文本，重试不重复插入同一轮结果。允许复制回答、将选中回答编辑后保存为笔记。没有 Key 或服务不可用时，阅读和手工笔记仍可使用。

### FR08 笔记

学生可以在阅读页面、重点、题目或 AI 回答处创建笔记，也可以创建没有来源的课程笔记。每份笔记只有一个实体，可以关联多个来源；在不同入口编辑的是同一份笔记。

首期包含标题、正文、来源、创建时间和更新时间，支持基础文本或 Markdown、编辑、删除和课程内检索。标签和置顶可后续补充。正式保存需服务端确认，离开未保存内容前提示；保存失败保留输入。删除来源后保留正文和来源摘要，跳转时提示来源不可用。

### FR09 习题的三种来源

| 来源 | 触发方式 | 内容范围 | 入库方式 |
| --- | --- | --- | --- |
| 重点生成 | 重点详情中点击生成 | 当前重点和学生可见的关联页面 | 程序校验合格后直接可练习 |
| 学生上传 | 课程习题区上传 PDF 或 DOCX | 文件中的现有题干、选项、答案和解析 | 学生预览、纠正并确认导入 |
| 课件自动生成 | 新课件的文字处理和来源映射就绪后自动触发 | 按整份课件章节抽样，不只读取开头 | 程序校验合格后直接可练习 |

三种来源进入同一课程题库，保留来源标签和来源详情。课件题库也可从该课件详情进入，重点题库可从重点进入；不是建立互不相通的三套题库。

建议首次生成每批 5 题，可采用 3 道单选加 2 道简答，允许按支持范围调整。少量题目只代表抽样练习，不代表覆盖全部考点。材料不足时少生成并说明原因，不为凑数量编造内容。补充生成由学生明确触发，重复打开或重试上传不再次自动生成。

AI 生成题保留题干、题型、选项、参考答案、解析及真实来源。程序校验必填内容、单选答案与选项一致性、来源合法性和明显重复；通过后不等待人工发布审核。提供问题反馈和编辑入口，程序校验不能保证知识正确。

上传文件只抽取已有内容，不自动为无答案题补造标准答案。预览标记未识别或缺失部分；确认前可修改或取消，确认操作不能重复导入。扫描件或不可提取文字的文件明确提示限制。题目由当前学生管理，不提供首期公共题库。

### FR10 练习与作答

从课程、课件、重点、错题或收藏开始练习，可选择支持的题型和数量。保存每次作答与当时题目版本，退出后可以继续未完成练习。编辑题目不得改变历史成绩或历史解析。

单选题有标准答案时在提交后由后端判分，提交前不下发答案；乱序选项使用稳定标识。没有可靠答案时记录作答并进入自评，不计算客观正确率。简答题先自行作答，再查看参考答案，以不会、部分掌握、已掌握自评；首期不做 AI 自动评分。

重复提交不能重复计分。跳过不是答错；未完成、主观自评和无答案题不混入客观正确率分母。没有已判分单选题时显示暂无正确率。展示完成情况、错题和来源跳转，但一次答对不自动修改重点掌握状态。

### FR11 错题与收藏

单选判错或学生自评为不会、部分掌握时可进入错题集。同一用户同一题保留一条错题索引，关联多次作答历史和错误次数。后续答对保留历史，不直接从错题集消失；学生可手动移出。

题目收藏和错题状态独立，取消收藏不移除错题。阅读页收藏为可延后增强项。题目删除不改写既有练习记录，无法再次练习时说明原因。

### FR12 数据生命周期与失败处理

删除单份课件需确认，清理原文件、预览和检索结果；保留已有笔记、题目、作答和对话中的来源摘要，提示原课件不可访问。后台任务发现课件或课程已删除后停止写入，不能产生新的孤立题目。

长时间处理使用后台任务，进度刷新不重复触发工作。服务重启后可以识别中断任务并恢复或明确标为失败；重试次数受限。失败信息说明影响范围和下一步操作，不暴露 Key、数据库密码和内部堆栈。

## 5 通用质量要求

- 状态可见：区分加载、空内容、成功、失败及部分成功，输入失败后尽量保留学生内容。
- 来源可追溯：页面、重点、题目和笔记的关联使用稳定标识，课程改名不使引用失效。
- 数据可靠：刷新、重新登录和服务重启后的持久化行为纳入测试，文件和数据库共同备份。
- 安全：跨用户访问由服务端拒绝；笔记与 AI 内容安全渲染；上传、调用额度和后台并发有上限。
- 可演示：常用桌面浏览器完成主流程，窄屏保证侧栏可切换；不在未测量时承诺响应秒数、识别准确率或并发规模。
