## 优先级与估算

使用 1、2、3、5、8、13 估算相对复杂度，PB02 课程管理暂作 3 点参照。估算不等于工时或日历天。各故事包含必要的异常处理和验证；公共工程、CI、过程材料作为支持任务安排，不重复计入故事点。

## 验收标准

下列场景使用 Given、When、Then 表达，中文分别对应前置条件、操作和预期。测试执行编号见[质量与验收](quality-and-acceptance.md)。

### PB01 账号与隔离

- Given 未注册学生，When 使用有效账号信息注册并登录，Then 进入本人首页，有效会话内刷新仍已登录，退出后受保护接口不可访问。
- Given 两个已有账号，When A 使用 B 的课程、文件或其他学习记录标识发起访问，Then 服务端拒绝访问且不返回 B 的内容。
- Given 错误密码、重复账号或失效会话，When 提交或访问，Then 得到明确提示，密码及密钥不写入响应或普通日志。

### PB02 课程首页

- Given 已登录且课程为空，When 创建名称为“软件过程”的课程，Then 首页出现对应卡片，刷新和重新登录后仍存在。
- Given 已有课程，When 修改名称，Then 首页和详情同步更新，已有引用不受影响。
- Given 空白或超出已公布长度限制的名称，When 保存，Then 前后端均拒绝并保留可修改内容。

### PB03 课件上传

- Given 本人课程，When 上传有效且未超过配置限制的 PPTX，Then 获得唯一课件记录并显示处理状态。
- Given 超限、损坏或伪装格式文件，When 上传，Then 明确拒绝且不留下可见的假成功记录。
- Given 同一次上传请求重复提交，When 系统处理，Then 不产生重复课件；学生明确发起的另一次上传可成为独立课件。

### PB04 课件处理

- Given 测试课件含文字、表格、图片及隐藏页，When 完成处理，Then 原始页序与预览、文字和引用映射一致；无法一致时不发布错位结果。
- Given 文字可提取而某项处理失败，When 查看状态，Then 看见各阶段的真实状态与可用能力，不因出题失败禁止阅读。
- Given 中断或可恢复失败，When 重启或有限重试，Then 有明确结果且不重复发布页面、索引或题目。

### PB05 课件阅读

- Given 预览已就绪，When 翻页、输入页码或使用缩略图，Then 显示指定原始静态页面和准确页码。
- Given 上次停在第 n 页，When 关闭后重新打开，Then 可以继续第 n 页，且不因此把重点改为已掌握。
- Given 越界页码或不可用预览，When 操作，Then 提示有效范围或处理状态，不显示其他课件内容。

### PB06 重点清单

- Given 本人课程，When 新增、编辑或删除重点，Then 操作持久化，刷新后结果一致。
- Given 包含多条重点的文本，When 使用拆分建议并确认，Then 只保存确认内容，不静默覆盖原文。
- Given 重点已有关联，When 修改其正文，Then 提示原关联需要重新核对，笔记和题目不被连带删除。

### PB07 重点定位

- Given 当前课程有可检索课件，When 对重点发起定位，Then 结果显示存在的课件与页码、依据片段，点击可跳转原页。
- Given 没有足够匹配材料，When 定位结束，Then 明确显示未找到或待核对，不能编造页面或引用其他课程内容。
- Given AI 服务不可用，When 定位，Then 可返回带提示的关键词候选或明确失败，已保存重点仍保留。

### PB08 关联校正与掌握

- Given 自动候选，When 学生确认、排除或手动选页，Then 记录操作，重新定位不覆盖人工校正。
- Given 任一重点，When 学生调整掌握状态，Then 刷新后保留，打开页面和答对题目不会自行改为已掌握。
- Given 一个重点关联多页，When 从详情打开任一来源，Then 跳转对应页，来源状态与掌握状态分别展示。

### PB09 AI 答疑

- Given 当前页已显示，When 发送问题后立即切页，Then 已发送问题引用发送时的页，新问题使用新的当前页。
- Given 回答含页面引用，When 点击，Then 只能跳转本次提供且本人有权访问的真实页面；补充解释与课件依据可辨认。
- Given 超时、无 Key、额度不足或主动停止，When 交互结束，Then 显示实际状态，保留输入，重试不重复插入相同轮次，阅读仍可用。

### PB10 笔记

- Given 页面、重点、题目或 AI 回答，When 创建并保存笔记，Then 笔记带来源，课程笔记列表可找到同一实体。
- Given 已编辑未保存或保存失败，When 离开或重试，Then 提示未保存并保留输入；服务器确认后才显示已保存。
- Given 笔记已保存，When 编辑、检索或删除，Then 所有入口结果一致，正文中的不安全 HTML 不被执行。

### PB11 重点习题

- Given 重点有足够的有效关联内容，When 点击生成，Then 合格题目立即可练习，显示重点和真实来源页。
- Given 材料不足或返回格式错误，When 生成结束，Then 不发布无效题；少于请求数量时说明情况。
- Given 再次进入重点页面，When 浏览，Then 不自动重生成；明确补充生成时才新增并进行去重检查。

### PB12 课件自动习题

- Given 新课件文字和页码映射就绪，When 自动生成任务执行，Then 基于整份课件分段抽样，题目与来源页关联。
- Given 自动任务成功后重复打开课件或恢复任务，When 系统检查，Then 同一处理版本不再次创建同批习题。
- Given 出题失败，When 阅读课件，Then 阅读正常且显示出题失败及重试入口，不声称少量题已覆盖全部知识点。

### PB13 上传习题

- Given 含题目文字的 PDF 或 DOCX，When 上传，Then 展示可编辑预览、原始位置和未识别部分，确认前不进入正式题库。
- Given 原文没有答案或是扫描件，When 处理，Then 标记无答案或不可提取，不捏造标准答案或虚构识别成功。
- Given 已完成纠正，When 确认导入两次，Then 正式题目只入库一次，取消时不产生正式题目。

### PB14 统一题库

- Given 三种来源题目，When 打开课程题库或按课件、重点、来源筛选，Then 能查看同一批符合条件的题目并看到来源。
- Given AI 生成题已通过程序校验，When 查看题库，Then 无需人工发布审批即可开始练习，并可反馈或编辑错误。
- Given 已有历史作答的题目，When 编辑或删除，Then 历史保留原题目版本和答案，不改写既有成绩。

### PB15 单选练习

- Given 有标准答案单选题，When 加载题目，Then 客户端提交前不获得答案；提交后服务端返回判分和解析。
- Given 已提交请求重复到达，When 判分，Then 只记录一次作答、计分和错题变化。
- Given 选项乱序、跳过、未完成或无答案题，When 统计，Then 按稳定选项标识判分，仅纳入已客观判分题，零分母显示暂无。

### PB16 简答与自评

- Given 简答题，When 填写回答后查看参考答案并自评，Then 保存回答和不会、部分掌握或已掌握，不伪装为 AI 自动评分。
- Given 上传题没有可靠答案，When 作答，Then 可保存回答并自评，但不产生客观对错结论。
- Given 未完成练习，When 退出后继续，Then 保留已作答内容和当时题目版本。

### PB17 错题

- Given 单选判错或主观自评不会、部分掌握，When 提交，Then 同一用户同一题只保留一条错题索引，可查看多次作答。
- Given 错题后来答对，When 完成练习，Then 不静默删除历史；学生可主动移出错题集。
- Given 错题移出，When 查看历史练习，Then 原作答与当时成绩仍存在。

### PB18 收藏

- Given 本人题库中题目，When 收藏、再次收藏或取消，Then 状态持久化且无重复收藏。
- Given 同一题同时是错题和收藏，When 取消收藏，Then 不改变错题状态。
- Given 收藏题来源已删除，When 查看，Then 说明来源不可用；题目仍存在时可继续练习。

### PB19 复习进展

- Given 已保存重点和作答，When 查看课程概要，Then 分别显示定位、掌握和练习进展，不混用分母。
- Given 没有重点或已判分题，When 查看，Then 显示明确空状态或暂无正确率。
- Given 单题答对或仅打开课件，When 刷新统计，Then 不自动增加重点已掌握数量。

### PB20 删除一致性

- Given 有关联记录的课件，When 确认删除，Then 原文件、预览和索引不可再用，笔记、题目和历史仍有来源摘要。
- Given 课程有运行中任务，When 确认删除课程，Then 本课程学习数据不可再访问，任务不能再写入新结果。
- Given 未确认删除或非本人标识，When 操作，Then 不删除；非本人请求由服务端拒绝。

### PB21 当前页图片答疑

- Given 图片能力已验证且学生选择使用当前页图片，When 提问，Then 请求使用当前页图片及必要文本，界面显示图片上下文。
- Given 实际没有发送图片，When 回答，Then 不声称已看懂图表；明确需要提供的内容。
- Given 图片接入或转换失败，When 提问，Then 可以提示后改用文字，不影响阅读和已有笔记。

## 精化与状态维护

故事状态使用待办、进行中、待验证、完成；有阻塞时记录阻塞原因及下一步。当前文档不维护虚构的完成量，实际状态以团队选择的项目看板为准，并在评审时保存快照。

PB20 跨阶段实施：已交付课程管理时就应验证课程删除，已交付题库时再补充题目和历史一致性场景；完整故事只有全部适用场景通过才标为完成。
