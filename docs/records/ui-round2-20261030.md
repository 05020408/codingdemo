## 1 范围与交付

本轮是既有功能的体验改进，关联 PB04、PB05–PB09；不回填为 Sprint 1 原始交付或团队评审。保留第一轮纸面、蓝色和克制的衬线标题，以课件原页号作为阅读、定位与答疑之间的共同标记。

| 区域 | 实际变化 |
| --- | --- |
| 阅读工作区 | 桌面全局导航缩窄为图标栏；目录、课件、答疑并排，目录和答疑可独立收起；目录滚动不再带动整页 |
| 课件操作 | 上下页、原页码输入及范围提示；适合宽度与 125/150/175/200% 缩放，放大仅在课件内部滚动；页码更新地址并串行保存续读位置 |
| 重点流程 | 记下重点、定位原页、核对确认三步说明；掌握情况和定位状态筛选；重点正文与编辑分开，未保存修改明确提示并禁止定位 |
| 依据与判断 | 原页号、文件名、连续原文、确认/排除与需核对状态；手动关联有独立标记；重新定位仍保留既有人工作出的判断 |
| 返回恢复 | 从重点进入原页后，返回原重点、筛选和列表页码，并滚动至结果；答疑历史选择存于地址，刷新、来源原页往返可恢复 |
| AI 答疑 | 本轮使用的页面、当前阅读页、下一问页面分别显示；设置折叠；等待、生成、完成、失败、停止与未知状态具名；保留显式重试与草稿离开确认 |
| 手机 | 阅读/答疑切换保留输入；目录横向排列，重点和历史纵向布局；课件放大不会撑宽整个网页 |

新建重点或批量保存成功后选中首条新重点，清除旧过滤条件，便于继续定位。历史列表只显示最近 50 段，这不是自动删除旧对话的承诺。会话与来源的权限、限额和校验仍由既有后端负责。

## 2 实现边界

改动集中在 Vue 组件和独立 `study-workspace.css`；移出旧阅读/重点/答疑样式，保留公共样式。阅读器已有的图片失败重载、阅读位置保存重试、隐藏与空白页原号均保留。页面切换时取消过期响应更新，来源跳页使用一次地址更新，避免页码与面板状态互相覆盖。Ctrl+Enter 与发送按钮遵循相同 AI 可用性、加载和额度约束。

没有新增业务 API、数据库迁移、依赖或 Docker；后端仅同步版本，前端包、锁文件及健康接口版本均为 0.4.2。笔记、题库、逐字流式回答和 OCR 不在本轮范围。索引仍为关键词检索，可选 AI 辅助规则未改变。

地址新增/沿用的界面状态为 `page`（课件原页）、`focus`（重点 ID）、`focusPage`（重点清单页）、`mastery`/`match`（筛选）、`chat`（会话 ID）、`panel=chat`（窄屏答疑面板）、`from=history`（返回答疑记录），重点返回使用 `#focus-results`。这些是前端导航参数，不放宽服务端访问权限。目录展开与缩放只保存在本次组件状态，不承诺跨刷新保存；未发送草稿只在收起/面板切换时保留，离开页面仍会确认。

## 5 实际失败与修正

首次批量保存 21 条时，后端已经成功保存，前端却显示 `Cannot read properties of undefined (reading '0')`。根因为本轮新增“选中首条新重点”的逻辑把既有批量接口的 `Focus[]` 返回值误当成 `{ ids: [] }`。改为 `request<Focus[]>` 并读取 `created[0]?.id`，重新批量保存 2 条通过，首条自动选中，列表计数正确。此前已成功的数据没有重复提交；最终合成课程共 25 条重点。此问题为本轮开发中发现并修复，不记为已发布版本故障。

浏览器曾保留一次编辑过程中的 Vite HMR 加载失败日志；修正后多次类型检查/构建通过，后续页面流程未出现新的浏览器 warn/error。不能把旧日志查询写成空数组。
