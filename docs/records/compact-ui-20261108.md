# 界面文案与信息密度优化（2026-11-08）

用户原始要求：“你帮我优化一下前端界面，现在感觉字太多太冗余了”。基于提交41227f4，分支ui/concise-copy。本轮调整Vue模板与样式，不修改后端、数据库、模型或AI提示词，应用版本标识保持0.4.4，通过本次Git提交区分界面增量，不移动既有标签。

## 调整原则与结果

围绕学生“进入课程、阅读原页、提出问题”做减法。沿用知笺的蓝绿配色、纸张阅读区和标题/正文层级；保留原页号作为阅读位置线索。移除重复口号，减少说明段落，使用原生details/summary承载需要时才查看的信息，不通过缩小字体或截断正文减少字数。

| 页面 | 调整 |
| --- | --- |
| 全局与首页 | 去掉侧栏复习路径、品牌副标题、首页介绍与重复面包屑；保留导航、搜索、计数和添加课程；无备注课程不再显示占位宣传语 |
| 课程与上传 | 去掉重复课程空间标签、默认描述和创建日期；保留真实备注及更新日期。上传区只显示格式、大小、页数上限及拖入提示 |
| 重点 | 去掉三步引导及重复定位说明，简化输入标签与结果标题；保留AI选择、将发送的材料与额度提示、原文引文、确认、排除、手动关联和异常状态 |
| 阅读与答疑 | 侧栏标题与空状态精简，提问来源合并为当前页及剩余额度；回答解释默认可见，课件依据、补充解释及回答限制按需展开。来源页、图片依据、摘要版本、复制回答均保留；未改写或截断已保存回答 |
| 摘要 | 简化空状态与进度说明，增加默认折叠的生成说明，保留生成前确认、共享额度、来源变化、失败和恢复提示；摘要正文全文保留 |
| 登录与历史 | 去掉装饰性英文口号及重复介绍；简化历史空状态和继续答疑入口 |

不删除或改写用户课程备注、课件文字及AI历史输出。提问设置内仍完整说明发送内容；图片与摘要选项的默认状态不变，生成和重试仍需用户主动操作。删除确认、未保存提醒、失败与过期提示不隐藏。回答限制在原生折叠入口中保留全文，并非删除免责声明。
