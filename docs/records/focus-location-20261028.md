## 已交付范围

- PB06：单条重点增删改查、分页、掌握状态筛选、按行与编号规则拆分预览、编辑预览后批量保存。每条最多 2000 字，原始输入最多 10000 字，一批最多 50 条。批量验证与写入为一个事务；重复请求不产生重复重点。
- PB04/PB07：Lucene 9.12.3 与 SmartChineseAnalyzer 页级索引；文字发布后自动建索引，已有课件回填，索引文件丢失后重建，独立状态/重试。检索限定本人当前课程、活动课件及已发布的文字/索引修订。
- PB07：最多 20 个候选页，关键词模式最多展示 5 项；保留课件名、原始页号和连续原文片段。可选 DeepSeek 重排，最多 5 项；未知/重复页面标识、伪造引文、无效结构或不完整回答均拒绝采用，明确回退关键词结果。
- PB08：确认相关、排除、按课件及页码手动关联；重新定位只替换自动候选，保留人工判断。正文修改使人工关联需要重新核对，掌握状态独立修改。确认项优先，候选项保留检索/AI 返回顺序。
- PB05：定位链接以 `page` 参数打开原始课件页，明确页码优先于续读位置；显示当前重点及返回定位结果入口，保存本次阅读位置。
- PB20：删除课件立即停止访问；清理文件、索引和未引用页面，被重点引用的页面仅留标识与原始页号墓碑并清除正文和资产引用。重点来源保留历史快照并标记不可打开。删除课程清除重点和所有关联；删除重点清除其内容和链接。

未实现阅读侧栏 AI 答疑、笔记和题库；不将此次 DeepSeek 重排误称为这些功能已完成。批量拆分当前为规则预览，未调用 AI。没有 OCR、向量检索或通用图片理解。

## 数据和并发约束

V3 新增 `focus_items`、`focus_slide_links`、`ai_calls`，并扩展页面墓碑和索引输入修订；V4 新增结果排序号。已执行的 V1/V2 未修改。新增幂等结果只缓存重点 ID，不缓存用户正文，删除后重放创建请求也不能取回已删内容。

定位为持久 `FOCUS_LOCATE` 任务，固定重点正文修订和可检索范围快照。领取后使用令牌、90 秒租约和 10 秒心跳；发布前重新核验所有权、当前任务、租约、重点修订与整个来源范围。编辑/删除取消旧任务；来源改变时丢弃结果并提示重新定位。过期任务标为中断，AI 状态不确定时记 UNKNOWN，不自动重发付费请求。

数据库连接明确使用 READ COMMITTED，课程→重点/课件→任务的写锁配合乐观版本，避免等锁后继续读取旧事务快照。新增两个客户端同时修改同一版本的回归：只有一项成功，另一项返回 VERSION_CONFLICT。掌握状态或人工关联写入会推进重点版本；背景定位完成不修改正文。

索引使用不可变的课件/索引修订/文字修订范围；数据库发布决定可见范围。旧检索结果还要按数据库活动状态和文字修订过滤。丢失索引不会伪称“没有匹配”；无任何就绪来源返回 PROCESSING_NOT_READY，部分就绪给出 PARTIAL_INDEX。

## DeepSeek 请求及真实用量

常规启动 AI 关闭，纯关键词定位可用。`Start-Backend.ps1 -EnableAi` 仅在后端进程加载本地密钥；默认每用户每天 10 次尝试，日期按 Asia/Shanghai。默认配置限额为 0 时禁止真实调用。请求目标仅由后端配置指定，HTTPS、禁止重定向、45 秒总请求超时、响应最多 256 KiB；测试允许回环 HTTP 替身。

请求使用 `deepseek-flash`、`thinking.type=disabled`、JSON 对象输出、最多 1200 个输出 tokens。输入只包含一条重点和至多 20 页各不超过 800 字符的候选片段。请求前锁用户额度并记录指纹；每任务每场景唯一，失败/未知也占一次额度。审计不保存完整 prompt、API Key 或完整响应，令牌用量只采用服务实际返回值。

本轮另经正式上传、索引、定位任务和 DeepSeek API 完成 **一次**真实业务请求：

| 项目 | 实际结果 |

| 重点 | `PAGE-01-NORMAL`，来自合成样本第一页 |

## 限制与后续

关键词检索依赖课件文本的表述；此次真实长课件结果中也有相关性较弱的候选，因此界面要求核对原文并提供排除与手动关联。尚未建立成套人工相关页标注集，不能报告准确率或召回率。优先补标注集，再决定是否需要同义词或向量召回。

未实测多实例共享 Lucene、超大课程集合、磁盘满、整进程强杀及提供商真实超时；当前面向单机实验项目。重点列表筛选和索引巡检适合当前样本规模，后续规模增长需分页巡检、性能基线与索引代际回收。此处不虚构尚未举行的 Scrum 会议、燃尽图、成员评审或 Sprint 完成结论。
