# 课程空间界面优化

日期：2026-11-09（北京时间）。用户提供课程详情页截图，要求“把这个界面也优化一下”。本轮使用frontend-design技能，应用版本保持0.4.4，不移动历史标签。

## 设计与实现

课程页的主要任务是找到并打开复习课件。截图中的左栏和较窄内容区占用了宽屏空间，单份课件的操作纵向堆叠。本轮将课程页与新版首页统一为顶部品牌、课程导航及账号入口，内容最高1600px、边距自适应；阅读器和摘要页保持既有导航。此前记录中“其他页面保留侧栏”是当时事实，本轮在此基础上扩展到课程页。

沿用墨蓝#172640、海绿#1b8982、浅底#f4f7fb、白色#ffffff，以及随课程稳定的主题色。课程标题使用中宋/宋体26—36px，正文使用既有系统字体。课程册页首字与彩色书脊延续首页主题；装饰隐藏于辅助技术，不添加虚构学习统计。

压缩课程头部，备注和更新日期并排并允许换行；三个标签保留。上传区集中选择/上传与已有文件要求，保留拖入、校验和状态提示。课件列表突出文件名、可用状态及阅读入口，正常状态与收起的处理详情同行，展开时显示完整阶段信息。打开课件为主按钮，核心摘要并排；下载与删除放在下一行，删除仍须输入完整文件名确认。失败状态与允许重试的阶段保留。

手机改为信息在上、操作在下，按钮和标签适配窄屏。新样式位于frontend/src/course-space.css，通过course-workspace限定主要作用范围；App.vue调整课程页导航，CourseDetail.vue和MaterialList.vue做必要结构调整，后端、数据库、接口与AI请求配置未改。
