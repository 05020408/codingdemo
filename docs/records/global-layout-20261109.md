## 实际调整

- 所有登录后页面共用顶部品牌、我的课程、账号和退出入口，移除阅读器和摘要页遗留侧栏；桌面导航72px，手机64px。增加键盘“跳到主要内容”入口，摘要正文改为 article，避免嵌套 main。
- 首页与课程页共用1760px内容上限和响应式边距，课程详情、摘要使用明确返回按钮；阅读器保留2360px工作区，并按新导航高度调整画布与答疑栏的可用高度。
- 摘要采用版本侧区和正文双栏，正文限制行宽、放大字号；长代码仅在正文内部滚动。手机改为纵向排列，保留版本、生成、编辑和下载操作。
- 答疑历史统一列表选择态、回答层级和间距，窄屏上下排列。登录/注册使用同一套字体、表单尺寸和手机边距；公共弹窗、焦点及错误提示同步整理。

修改集中于 App.vue、global-layout.css、样式入口和两处返回/语义模板。后端、数据库、DeepSeek配置与应用版本0.4.4未改变。
