# 取消默认账号AI日请求次数限制

2026-11-09，用户要求“把账号的ai请求次数限制去掉”。默认策略改为所有账号每日不限次数，覆盖重点AI辅助判断、摘要生成/恢复、文字及图片答疑/重试，不通过重置账号记录或虚构超大剩余额度实现。

## 实现与接口

- 本地启动脚本的默认AI_DAILY_REQUEST_LIMIT从10改为0。ReaderAiClient和DeepSeekReranker将0或负数解释为不限；正整数仍可显式启用共享日限额。AI是否可用只取决于AI开关和Key，与日限额配置分离。
- chat-capabilities与摘要State的remainingToday使用可空整数，null表示不限，AI关闭时仍为0。摘要预检/恢复、答疑执行和定位审计事务都适配无限模式；已有审计保留，同任务幂等与明确重试不变。
- 前端null时显示“请求次数不限”，正常启用摘要生成/继续生成和答疑发送/重试；有限模式仍按剩余值判断。定位说明改为“发起一次AI请求”，重试/恢复文案不再强调扣额度。
- 同步README、环境变量示例、需求、架构、摘要设计和接口契约。应用版本保持0.4.4，无数据库迁移，不修改DeepSeek模型和其他输入边界。
