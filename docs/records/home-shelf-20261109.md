# 首页课程书架视觉优化

日期：2026-11-09（北京时间）。用户提供2559×1392的首页截图，要求“这个页面能不能在优化一下，使用skill”。使用本地frontend-design技能，版本仍0.4.4，不移动历史标签。

## 设计判断与实施

截图中只有三门课程，原1200px内容宽度及小字号在宽屏占比不足。本轮以课程书架为主题，保留无侧栏的顶部导航，扩大内容区至最高1760px并使用自适应边距；标题32—44px、课程名23—28px，改善宽屏阅读比例。不是改浏览器缩放，也不试图用无关文案填满屏幕。

采用墨蓝#172640、海绿#1b8982、浅底#f4f7fb、白色#ffffff及课程既有配色。标题/册页使用中宋或宋体，控件和正文使用微软雅黑/系统无衬线，日期计数使用Consolas辅助。课程册页封面是主要视觉特征：真实课程名首字作为装饰，稳定课程配色、书脊和页线；装饰从辅助技术隐藏，标题仍保留完整可访问文本。没有新增学习进度或虚构统计。

搜索、数量和更新排序合并为同一工具行；手机变为数量/排序在上、搜索在下。桌面三列、1100及以下两列、640及以下单列，卡片最小高度322/294px；管理菜单位于封面右上，课程正文/日期/进入入口分层。此前home-workspace.css替换为home-shelf.css，main.ts更新引入，Courses.vue调整结构，后端/数据/AI配置未改。原布局实现文件名在历史记录中保留为当时事实。
