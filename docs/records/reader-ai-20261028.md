# v0.4.0 阅读侧栏 AI 答疑执行记录

日期：2026 年 10 月 28 日（北京时间）。用户直接指令：“开始实现阅读侧栏 AI 答疑功能”。本轮代理编码与自检，不替代团队评审、会议或个人贡献确认。

## 实际范围

- PB09：阅读器右侧“边读边问”，解释本页/举例/易错点快捷输入、连续追问、新对话、历史切换、复制、来源页跳转；手机通过课件/答疑面板切换。
- 请求在发送事务内固定问题、当前页、正文修订和可选图片资产。翻页只影响下一问；取消“延续”则不提供历史。最多4轮成功历史、3页正文，每页最多12000 UTF-16字符，截断有提示。
- 通过 Java HttpClient 请求 DeepSeek，无额外 Python 业务服务。默认整段显示，不包含逐字流式输出。AI 提供课件解释、补充解释、限制和最多3个引用，只有已提供页面和连续原文可成为文字引用。
- PB21：可选发送当前页预览 PNG（本地上限8MiB），默认不勾选；实际配置 deepseek-flash 支持图片时才展示可选能力。图片证据与文字引文分别标识，图片结论仍须对照原图。
- 持久化 chat_sessions/chat_turns，单段最多100轮、列表最近50段；课程详情提供答疑记录。关闭页面不会自动取消后台任务，回来可查看结果。
- 同课程同时仅一个活动答疑任务；90秒租约、10秒心跳、60秒HTTP超时、每500毫秒检查取消。每任务最多一次付费尝试；主动重试复用轮次、创建新任务，不自动重发失败/未知调用。
- 每日额度按用户、北京时间统计，与重点定位共用。取消已发出的请求不保证服务商退款。审计仅保存指纹、模型、状态、用量及技术信息；完整问题、回答作为用户自己的学习记录保存。
- 删除课件立即停止当前回答；保留问答和来源摘要，清空上下文正文/历史副本。课程删除清理轮次和会话。发送前与发布前重新检查归属、来源修订和任务令牌，旧任务不可恢复已删内容。

笔记及题库未实现。版本路线调整为 v0.4.0 阅读答疑，笔记独立后续推进，不声称整个 Sprint 2 已完成。

## 官方资料与边界

请求格式核对 [DeepSeek Vision](https://api-docs.deepseek.com/guides/vision/) 与 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。模型支持图片不等于本软件已经完成全课件OCR：本轮只在提问时附当前页图像，未把图像解析写入重点索引。

一次流程图识别和少量文字回答不代表对所有公式、图表、手写或复杂课件的准确率。程序只校验结构与引用，不证明解释的知识正确性；团队仍需核对实际课程样例。笔记保存、题库、错题和进度后续实现。
