# 阅读页宽屏与答疑可读性优化

日期：2026-11-09（北京时间）。用户提供阅读器截图，要求“把这个页面的前端也优化一下，使用skill”。使用frontend-design技能，应用仍0.4.4，不移动历史标签。

## 设计及实现

本页主要任务是在阅读课件时提出问题并核对回答。截图中的答疑栏偏窄、正文及控件偏小，宽屏内容受1920px上限约束；此前适合宽度可能让较高的课件需要在画布中滚动。本轮沿用知笺蓝绿配色和课件桌面结构，内容上限扩大到2360px，目录124px、答疑栏按屏宽取380—460px，中间课件使用剩余空间。保留左侧精简导航，不影响课程页和摘要页布局。

配色沿用墨蓝#172640、海绿#1b8982、画布灰蓝#e6ecf2、白色#ffffff及问题浅绿#eef6f4。文件名使用22px系统无衬线，答疑标题使用21px中宋/宋体，回答与问题桌面15px/1.9行高、手机14px；来源和设置12—13px，页码使用Consolas。课件保持画布主体，问题与课件依据分层呈现，不添加介绍或虚构统计。

默认缩放由“适合宽度”改为“适合页面”：图片加载后读取自然宽高比，按画布可用宽度与视口高度共同计算显示宽度，保留原图比例。窗口大小或横竖页变化时重新适配；125%—200%仍按画布宽度放大并在画布内部滚动。手机继续阅读/答疑切换及横向目录，专注模式与Esc退出、草稿保留不变。

调整标题、操作按钮、目录及状态区间距，答疑输入框增至90px并放大快捷问题、摘要/图片/追问设置与发送按钮。桌面答疑保持历史区内部滚动；展开设置或较矮窗口需要在面板内滚动查看完整内容。通过reader-page及reader-chat限定选择器，覆盖旧桌面紧凑规则，避免影响课程答疑历史页。实现涉及reader-workspace.css和MaterialReader.vue，后端、数据库、鉴权、API契约和AI配置未改。

## 实际验证

- vue-tsc与Vite生产构建通过，74模块。
- 合成API、自制SVG课件及自写回答文本，覆盖2560/1920/1440/1280/1101/1100/1024/751/750/390/320共11种宽度，另查1366×768、1920×720、2560×1440。无横向页面溢出或脚本错误；默认画布无内部滚动，桌面答疑宽度与15px字号符合设计，矮屏默认收起设置时发送按钮位于视口内。
- 横版、4:3和竖版图片自然比例保留且完整适配，150%放大仅画布滚动；检查非法页码、目录、专注/Esc、收起恢复草稿、窄屏阅读/答疑切换及展开设置。
- 引用跳转、提问页同步、附带摘要/图片/追问的替身请求参数、运行中禁止发送、停止及主动重试、图片失败重载、阅读进度保存失败及重试、提取文字展开、重点上下文及返回筛选、AI不可用时仍可读历史、课件加载重试及预览未就绪提示通过。13次写请求全部被浏览器替身拦截，无真实业务写入或AI调用。
- 首页、课程课件列表、复习重点既有合成界面复测通过，产物保存在忽略的.runtime目录，未覆盖历史证据。

首轮扩展脚本以精确名称查找返回链接时遗漏可访问名称中的“←”，导致检查超时；改为匹配实际名称后通过，不将脚本定位错误描述成产品功能故障。另在样式复核时提高答疑选择器的限定程度，使新字号与输入框尺寸覆盖原桌面规则。
