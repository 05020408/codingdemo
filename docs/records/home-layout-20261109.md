# 首页布局调整记录

日期：2026-11-09（北京时间）。原始要求：“能不能把主页左侧的侧边栏去掉，然后优化一下布局”。应用版本保持0.4.4，不移动历史标签。

## 实施范围

仅首页移除左侧栏，将知笺品牌、我的课程导航、头像、姓名与退出迁至顶部；退出失败信息仍可见。课程详情、阅读及摘要页面保留原有导航。首页内容居中，最大内容宽度1200px，桌面三列、平板两列、窄屏单列；调整标题、添加按钮、搜索、计数、卡片和空状态的对齐与间距。搜索、管理、分页与后台清理提示保持原行为，未增加统计字段或虚构课程信息。

App.vue按首页路由切换布局，home-workspace.css限定首页作用范围，main.ts按顺序引入。后端、数据库、鉴权、AI参数均未修改。
