# 复习重点界面优化

日期：2026-11-09（北京时间）。用户提供课程页“复习重点”截图，要求“你帮我把这个前端界面也修改一下”。使用frontend-design技能，应用保持0.4.4，不移动历史标签。

## 设计与实施

本页服务于学生选定重点、定位课件并核对原文。原添加表单横跨整页，将重点详情及相关页面推到下方；列表、元数据和证据字体偏小。采用左侧添加和清单、右侧当前重点和原文依据的布局，桌面330px侧区与弹性详情区顶部对齐；1100及以下侧区290px，950及以下改为上下布局，其中添加和清单暂并排，650及以下全部单列。课程顶部导航、课程信息和标签继续沿用上轮设计，不增加新的介绍或统计。

延续墨蓝#172640、海绿#1b8982、浅底#f4f7fb、白色#ffffff、引用浅绿#f2f8f5。选中重点以浅绿底和彩色边线识别；当前重点使用中宋/宋体24—30px，列表15px，桌面原文依据15px、手机14px，正文和控件仍使用系统字体。原页号作为来源标记，与课件名称和确认状态区分，原文引用保持明确边线。该页的视觉重点是课件证据，不使用额外装饰或动画。

添加表单和重点清单集中于侧区，正常状态下清单内部最多620px滚动，窄屏360px；保留掌握/定位筛选、分页及选中态。右侧整理重点标题、掌握情况、折叠编辑、定位按钮及AI辅助说明，放大来源卡片、原文依据和查看原页/确认/排除操作。手机来源和操作换行，页面不横向滚动。加载、空态、定位中、失败、AI降级、来源删除及需要重新核对等提示保留。

实现仅调整FocusPanel.vue模板结构，新增focus-desk.css并由main.ts引入。业务处理函数、后端、接口、数据库、鉴权及AI配置未改。查看首轮手机截图后发现，从平板网格切换为纵向flex仍继承align-items:start，导致添加区和列表收窄；改为stretch，并增加手机表单/详情同宽检查后复测通过。
